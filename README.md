## Descrizione
"ECHOES: The Anomaly Hunter" è un Gioco di Ruolo (GDR) a turni con ambientazione fantascientifica. Il giocatore interpreta un Cacciatore di Anomalie che esplora settori ostili, combatte nemici alieni, raccoglie oggetti tattici (loot) e gestisce il proprio inventario. L'applicazione è progettata in Java seguendo rigorosamente i principi SOLID, pattern architetturali (MVC) e design pattern (Strategy, Repository).

## Istruzioni per l'esecuzione
Il progetto è gestito tramite Gradle ed è progettato per essere multipiattaforma.
Assicurarsi di avere il JDK 17 (o superiore) installato. Da terminale, posizionarsi nella root del progetto ed eseguire i seguenti comandi:

1. Per compilare il progetto ed eseguire i test automatizzati:
   `./gradlew build`

2. Per eseguire l'applicazione (Avvio interfaccia grafica JavaFX):
   `./gradlew run`
